DYNAMIC CLONER MODE IMPLEMENTATION - COMPLETE ✅
================================================================================

PROBLEM SOLVED:
The banner said "✅ Simple Copy Trading Bot initialized (UNIVERSAL CLONER MODE)" 
even though we have dex/action/mint and can build. That can starve the builder path.

SOLUTION IMPLEMENTED:
Dynamic flag that uses builders when fields are complete, cloner when incomplete.

This implementation successfully prevents builder starvation by dynamically
selecting the execution mode based on data completeness. When we have complete
fields after parsing and inference, we use builders. When any field is missing
or unknown, we fall back to the cloner.

The current event with complete fields after inference will now properly use
the builder path instead of being forced into cloner mode.
